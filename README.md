Anveshana – Explore the World
Anveshana is a full-stack web-based Tourism Management System developed using PHP and MySQL. It allows users to explore destinations, book curated travel packages, and manage bookings securely through a centralized digital platform.

This project was developed as part of an MCA Minor Project and demonstrates full-stack development, authentication systems, role-based access control, and secure database integration.

 Features
 User Module
User Registration & Login

Secure Session Management

OTP-Based Password Reset

Browse & Filter Destinations

View Detailed Travel Packages

Book Travel Packages

UPI-Based Payment Confirmation

Downloadable Booking Receipt

Booking History

Profile Management (Email, Password, Avatar)

Feedback Submission

Admin Module
Role-Based Access Control

Manage Users (View/Delete)

Add / Update / Delete Destinations

Manage Travel Packages

Monitor Bookings

View User Feedback

Security Features
Password Hashing

Session-Based Authentication

Role-Based Authorization

Server-Side Input Validation

OTP-Based Password Recovery

Transaction ID Logging

System Architecture
The project follows a Three-Tier Architecture:

Presentation Layer
HTML5, CSS3, JavaScript, Bootstrap

Application Layer
PHP (Backend Logic & Session Management)

Database Layer
MySQL (Relational Database)

Tech Stack
Frontend: HTML5, CSS3, JavaScript, Bootstrap

Backend: PHP

Database: MySQL

Server: Apache (XAMPP)

Tools: VS Code, phpMyAdmin
